# MLW History Explorer

**An interactive history, research paper, and data model for Major League Wiffleball (MLW), 2009–2026.**

![Champions timeline](figures/01_champions_timeline.png)

MLW began in 2009 as a backyard concept in Brighton, Michigan, and has filmed its seasons since 2010. This project turns the 17-table *MLW History Dataset (Research Edition)* into something you can explore, cite, and extend.

> **Live explorer:** https://claude.ai/artifact/SwqALSALC54tAEWsDtz1x6 (or open `site/index.html` locally; it is a single file)

## Headline findings

1. **MLW went from dynasty to parity.** The Western Wildcats won 5 of the first 6 World Series (2010–2015). Across 2016–2025, 10 titles went to 7 different franchises, and the title-concentration index (Herfindahl) fell from 0.72 to 0.16.
2. **The Wildcats still reached 10 of 16 finals**, more than any team, but won only one of the last ten (2018). They lost four finals (2013, 2016, 2020, 2021), and each time to a first-time champion.
3. **Eight franchises have won a title.** The Wildcats lead with 6; Eagles, Mallards and Diamondbacks have 2 each; Cardinals, Predators, Gators and Magic have 1. The Coastal Cobras have lost both finals they reached (2017, 2022).
4. **Finals are close.** 7 of 16 series went to Game 5, only 5 were sweeps, and two champions (2017 Mallards, 2023 Magic) came back from 0–2.
5. **Perfect games are getting spread out.** Kyle Schultz threw 4; Tommy Coughlin, Jordan Robles and Caden Irwin threw 2 each; five other pitchers threw 1 (15 total, 2010–2026).
6. **The retrieved batting tables show a more patient league in 2026**: walk rate 16.8% → 28.3% of plate appearances, strikeout rate 46.7% → 39.1%, home runs per plate appearance 8.4% → 5.5%. *Caveat: these are leader tables (17 and 27 batters), not full leagues.*
7. **The stage got bigger.** World Series moved from Cultz Field (2010–2017) to The Meadows (2018–2021), then to SoFi Stadium, Mercedes-Benz Stadium, AT&T Stadium and LMU's George C. Page Stadium (2022–2025).

## The data model

![Data model](figures/10_data_model.png)

Keys are **team name**, **year** and **player name**. There is no surrogate ID, so spelling must match exactly (see known issues for the Seahawks naming problem).

![Pipeline](figures/11_pipeline.png)

## Quick start

```bash
git clone <your-repo-url> && cd mlw-history-explorer
pip install pandas matplotlib openpyxl

python scripts/analyze.py      # writes data/analysis.json
python scripts/figures.py      # writes figures/*.png
python scripts/build_site.py   # writes site/index.html
open site/index.html           # no server needed
```

Example analysis:

```python
import pandas as pd
ws = pd.read_csv("data/mlw_world_series.csv")
print(ws.groupby("champion").size().sort_values(ascending=False))
```

## Coverage and known issues

![Coverage](figures/09_coverage.png)

The dataset deliberately **does not invent missing rows**. Strong: championships, division champions, perfect games, venues, media. Thin: full box scores, season stat tables (only 2017 and 2026), complete rosters, and awards beyond World Series MVP.

Inconsistencies found while building this project:

- Pacific Predators appear in 2017 batting and a 2017 perfect game, but `teams_history` dates them from 2019.
- "Seahawks" and "Southern Seahawks" may be the same franchise.
- The 2022 note says "second straight World Series MVP", but no 2021 MVP is named.
- World Series MVP is explicit for only 4 of 16 years.
- `mlw_records` omits Coughlin's and Robles's two perfect games each.
- Tommy Coughlin's 2014 retirement sits next to 2017 appearances.
- Division champions end at 2024.
- The 11-inning 2019 game has no confirmed opponent.

## Roadmap

From the dataset's own archival plan: (1) every game and box score 2010–2025, (2) every season's batting and pitching table, (3) full rosters by season and franchise, (4) All-Star Game and Home Run Derby history, (5) complete award history, (6) game-to-video links, (7) franchise and name reconciliation. Adding a `team_id` and `player_id` layer would fix most join problems.

## Method and provenance

All values come from the supplied tables, which cite official MLW pages (`data/mlw_sources.csv`). Derived numbers (title counts, concentration index, batting rates) are computed in `scripts/analyze.py`; nothing is hand-entered. Walk, strikeout and home-run rates are pooled sums over the listed batters, not averages of averages.
